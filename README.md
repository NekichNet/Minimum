# Minimum — Минималистичный мессенджер

**Minimum** — это современный кроссплатформенный мессенджер с открытым исходным кодом, построенный на базе фреймворка **Avalonia UI**. Проект ориентирован на высокую скорость работы, простоту интерфейса и надежную доставку сообщений.

## 📌 О проекте

Проект создан как демонстрация возможностей C# и Avalonia для создания десктопных приложений с единой кодовой базой для Windows, Linux и macOS. Основная идея — убрать всё лишнее («минимум») и оставить только функциональный инструмент для общения.

## ✨ Основные возможности

* **Регистрация и аутентификация:** Создание учетных записей и безопасный вход.
* **Обмен сообщениями в реальном времени:** Мгновенная отправка и получение текстовых сообщений.
* **Персонализация:** Поддержка светлых и темных тем оформления, соответствующих системным настройкам.
* **Кроссплатформенность:** Полноценная работа на Windows, Linux и macOS.

## 🛠 Стек технологий

### Клиент (Minimum.Client)

* **Язык:** C# 12 / .NET 8
* **UI-фреймворк:** [Avalonia UI](https://avaloniaui.net/) (MVVM-паттерн)
* **Реактивность:** `ReactiveUI` для обработки потоков данных и обновлений интерфейса.
* **Стилизация:** Использование Fluent Design.

### Сервер (Minimum.Server)

* **Язык:** C# / ASP.NET Core
* **Связь:** WebSockets / SignalR (для Real-time взаимодействия).
* **База данных:** SQLite / Entity Framework Core (для хранения пользователей и истории сообщений).

## 🏗 Как это работает (Архитектура)

Проект разделен на логические блоки:

1. **Shared:** Общие модели данных (DTO), которые используются и клиентом, и сервером.
2. **Server:** Обрабатывает запросы, управляет сессиями пользователей и сохраняет историю в базу данных.
3. **Client:** Отвечает за отображение интерфейса. Использует архитектуру **MVVM** (Model-View-ViewModel):
* *Views:* Описание интерфейса на XAML.
* *ViewModels:* Логика обработки действий пользователя.
* *Models:* Данные приложения.



## 🚀 Запуск проекта

### Требования

* [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
* IDE (Visual Studio 2022, JetBrains Rider или VS Code)

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/NekichNet/Minimum.git
cd Minimum

```

### Шаг 2: Запуск сервера

Сервер должен быть запущен первым, чтобы клиент мог к нему подключиться.

```bash
cd Minimum.Server
dotnet run

```

### Шаг 3: Запуск клиента

Откройте новое окно терминала:

```bash
cd Minimum.Desktop
dotnet run

```

## 📖 Инструкция по использованию

1. **Создание аккаунта:** При первом запуске перейдите на вкладку регистрации и создайте профиль.
2. **Поиск собеседника:** Используйте поиск по логину, чтобы найти другого пользователя.
3. **Общение:** Нажмите на чат в левой панели и начните вводить сообщения.
4. **Настройки:** В меню настроек вы можете изменить тему оформления или отредактировать данные профиля.
